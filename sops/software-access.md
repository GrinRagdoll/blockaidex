# Standard Operating Procedure: Software and License Access

**Audience:** Employees and managers  
**Owner:** IT Service Desk / Software Asset Management

## Purpose

Use this procedure to request approved business software and any required paid license. Access is granted according to role, business need, data-handling requirements, and license availability.

## Approved tools

The following tools are available through organization-managed deployment or account provisioning:

| Tool | Typical use | Access and license notes |
|---|---|---|
| Jira | Project planning, issue tracking, and team workflows | Request the appropriate project and permission level. |
| Visual Studio Code (VS Code) | Source-code editing and development | Install the approved company build; request any extension or add-on separately if it requires review or a license. |
| Power BI | Business reporting and dashboards | A license may be required for publishing, sharing, or viewing premium content. State the required work and audience. |

Use the company software portal where the tool is available for self-service installation. Do not install unapproved software, use personal accounts for company data, or buy a license on behalf of the organization without authorization.

## Requesting access or a license

1. Submit a request through the IT service portal under **Software / Application Access**.
2. Include the tool name, business purpose, required features or license tier, project or cost center, and requested duration if access is temporary.
3. Identify the manager or budget owner who can approve the request. Include their approval if the portal requires it.
4. For Jira, specify the project and access level. For VS Code, identify any extensions that require review. For Power BI, specify whether you need to create/publish reports or only view them.
5. Submit the request and retain the ticket number. IT or the software owner may ask for additional information or security review.

## Fulfillment and verification

IT or the application owner checks business need, manager approval, security requirements, and license availability. If approved, IT will assign the license or provide installation instructions through the managed software portal. Sign in with your company account and verify that the granted access matches the request. Do not share accounts or license seats.

If a request is declined or delayed, review the service ticket for the reason and any available alternative. Contact the service desk through the ticket for clarification; do not obtain an unapproved substitute license.

## Changes and offboarding

Request a change through the same portal when your role, project, or required license tier changes. Notify IT when access is no longer needed. Managers should include software access in role-change and offboarding notifications so unused licenses can be reclaimed and access removed.
